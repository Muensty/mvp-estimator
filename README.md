# MVP Estimate & SOW Builder

An internal, local-first React/TypeScript application for creating one project record and using it consistently across estimate previews, editable Word SOWs, matching PDF SOWs, and editable PowerPoint estimate slides.

## Run it

Requirements: Node.js 24+ and npm 11+.

```bash
export NPM_CONFIG_CACHE=/workspace/.npm-cache
npm install
npm run dev
```

Open the local URL shown by Vite. The default development port is `5173`.

Useful checks:

```bash
npm test
npm run build
npm run generate:samples
```

## First-version workflow

1. Create or duplicate a project.
2. Enter client context and edit the client-facing narrative.
3. Enter scope lines, hours, project-wide rates, and any line-item rate overrides.
4. Confirm project-specific commercial terms and preset practices.
5. Review unresolved items and the shared document preview.
6. Export a draft or a Ready for review package.

Projects auto-save to browser local storage. Use **Download backup** to move data between browsers or machines, and **Restore backup** to reopen it. Exporting creates an immutable snapshot and a concise comparison with the preceding exported version.

## Maintaining business rules

- Project-type scope presets and their source citations are in [`src/data/presets.ts`](src/data/presets.ts).
- Clause options and their source citations are in [`src/data/clauses.ts`](src/data/clauses.ts).
- Calculation and unresolved-item rules are in [`src/lib/calculations.ts`](src/lib/calculations.ts).
- The shared client-facing document model is in [`src/lib/documentModel.ts`](src/lib/documentModel.ts).
- Word, PDF, and PowerPoint layouts are in [`src/lib/exporters`](src/lib/exporters).

Rates, revisions, variance, payment schedules, hosting, training, copywriting, and SEO selections remain editable per project. The supplied sources do not establish a company-wide terms master, so source language is labeled provisional where appropriate.

## Reference handling

The first version uses the provided files as project-specific structure and style references:

- TeamPlate 2 scope: `01_VWG_TeamPlate_2_Estimate_082126_Signed.pdf`
- Custom website scope: `02_New_Harbor_Custom_Website_Estimate_011426.pdf`
- Existing-site updates and concise SOW structure: `03_Wakefield_Website_Updates_SOW_102826.docx`
- Editable estimate-slide layout and branding: `04_Clearsight_BlackArch_Preliminary_Estimates_092326_v4.pptx`
- Supplemental commercial language: files `05` and `06`

Client-specific names, dates, fees, signatures, and negotiated terms are not copied into new projects. Internal notes are excluded from the shared document model and all exports.

## Current limitations

- Data is local to one browser unless a backup is restored.
- No CRM, accounting, e-signature, cloud database, or external document-template integration is included.
- Legal and payment language still requires MVP review before client delivery.
- Word and PDF share the same content model but are generated by separate layout engines, so exact pagination can differ.
- PowerPoint paginates long estimate tables across multiple editable slides.
